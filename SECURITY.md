## Reporting a Vulnerability

We take the security and integrity of the MCPx transactional runtime seriously.

If you believe you have discovered a security vulnerability or vulnerability in the WebMCP postMessage isolation boundary, please report it responsibly:

1. **Private GitHub Security Advisory**:
   - Use the "Report a vulnerability" button on our GitHub repository Security tab.

2. **Alternative Contact**:
   - Reach out to the maintainers directly via repository issue or project contact mechanism requesting a private disclosure channel.

### Please Include:
- Description of the vulnerability and potential impact.
- Step-by-step reproduction instructions or proof-of-concept payload.
- Affected WebMCP transport or PostgreSQL persistence components.

We ask that you do **not** disclose the issue publicly until maintainers have had an opportunity to investigate and address it.
